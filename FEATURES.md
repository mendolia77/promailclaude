# 🚀 SmartMail - Guida Completa alle Funzionalità

### 3. 🎯 **Sistema di Filtri Intelligenti**

#### Auto-Categorizzazione
Le email vengono automaticamente smistati in categorie predefinite:

- **🏢 Lavoro**: Email da domini aziendali
- **👥 Personale**: Email da contatti privati
- **⭐ Importanti**: Email starred o flaggate
- **📎 Con Allegati**: Email con file allegati
- **🛒 Shopping**: Ordini, tracking, spedizioni
- **📰 Newsletter**: Email con link "unsubscribe"

#### Filtri Personalizzabili
Crea filtri custom con regole avanzate:

**Filtri Mittente:**
- Da indirizzo specifico (`mario.rossi@example.com`)
- Da dominio (`@company.com`)
- Da nome mittente

**Filtri Contenuto:**
- Parole chiave nell'oggetto
- Parole chiave nel corpo
- Case sensitive/insensitive

**Filtri Allegati:**
- Ha allegati (sì/no)
- Tipo MIME specifico (PDF, immagini, etc.)
- Nome file allegato

**Filtri Avanzati:**
- Dimensione email (maggiore/minore di X KB)
- Data ricezione (dopo/prima di)
- Flag (starred, letta, importante)

**Operatori Logici:**
- **AND**: Tutte le condizioni devono essere vere
- **OR**: Almeno una condizione vera
- **NOT**: Negazione di una condizione

### 4. 🤖 **Intelligenza Artificiale Integrata**

#### Smart Learning Engine
SmartMail **impara dalle tue azioni** e diventa sempre più intelligente:

**Apprendimento Automatico:**
- Monitora quando sposti manualmente le email
- Rileva pattern ripetitivi nei tuoi comportamenti
- Calcola la **confidence** (0-100%) per ogni pattern
- Genera suggerimenti quando raggiunge soglia minima (3+ azioni simili)

**Esempi Pratici:**

```
Scenario 1: Shopping su Amazon
1. Ricevi email da "noreply@amazon.it"
2. La sposti manualmente in "Shopping"
3. Lo fai 3 volte
4. SmartMail suggerisce: "Vuoi creare un filtro automatico per Amazon?"
5. Accetti → Tutte le future email Amazon vanno in Shopping automaticamente
```

```
Scenario 2: Email di lavoro
1. Ricevi 5 email da "@company.com"
2. Le sposti tutte in "Lavoro"
3. SmartMail suggerisce: "Filtro per dominio @company.com?"
4. Accetti → Categorizzazione automatica attivata
```

#### Suggerimenti Smart

**Suggerimenti Filtri:**
- **Alta priorità** (confidence >75%): Azione ripetuta 3+ volte
- **Media priorità** (confidence >60%): Pattern identificato su 5+ email
- **Bassa priorità** (confidence >50%): Tendenza emergente

**Rilevamento VIP:**
- Analizza quante volte marchi email come "importanti"
- Suggerisce di creare categoria VIP per quei mittenti
- Notifiche prioritarie per email VIP

**Rilevamento "Rumore":**
- Identifica newsletter mai lette
- Email con "unsubscribe" che ignori
- Suggerisce di silenziarle o cancellarti

**Quiet Hours (in sviluppo):**
- Analizza quando NON leggi email (notte, mattina presto)
- Suggerisce orari per disattivare notifiche
- Personalizzabile

## 🎯 Come Usare le Funzionalità

### Creare un Filtro Personalizzato

1. Vai su **Impostazioni** → **Gestione Filtri**
2. Tocca il pulsante **"+ Nuovo Filtro"**
3. Scegli:
   - **Nome filtro** (es. "Email Urgenti")
   - **Emoji icona** 🔥
   - **Colore** (rosso)
4. Aggiungi regole:
   - Mittente contiene: `@azienda.com`
   - **AND** Oggetto contiene: `urgente`
5. Seleziona categoria destinazione: **Importanti**
6. Salva

### Accettare un Suggerimento IA

1. Vai su **Gestione Filtri** → Tab **"Suggerimenti IA"**
2. Vedrai card come:
   ```
   🤖 Automatizza Amazon
   Hai spostato 8 email da Amazon in 'Shopping'
   Confidence: 92%
   → Shopping
   [Ignora] [Applica]
   ```
3. Tocca **"Applica"**
4. Il filtro viene creato automaticamente!

### Usare lo Swipe

1. Nella inbox, **swipe destra** su un'email
2. Background diventa **verde** (archivia)
3. Swipe ancora più a destra → **arancione** (importante)
4. Rilascia quando vedi l'icona che vuoi
5. **Swipe sinistra** per eliminare (rosso)

### Vedere le Statistiche

1. Tocca **hamburger menu** o **icona analytics**
2. Dashboard mostra:
   - Tempo risparmiato questa settimana
   - Email gestite automaticamente
   - Distribuzione per categoria
   - Insights di produttività
   - Grafico attività settimanale

## 🧠 Come Funziona l'IA

### Algoritmo di Apprendimento

```kotlin
1. UserAction viene registrata quando:
   - Sposti manualmente un'email
   - Marchi come importante
   - Archivi/Elimini

2. SmartLearningEngine analizza:
   - Sender email e dominio
   - Keyword frequenti nell'oggetto
   - Azione ripetuta (es. sempre -> Shopping)

3. Calcola Confidence:
   confidence = (azioni_simili / totale_azioni)

   Esempio:
   - 3 email Amazon → Shopping
   - 0 email Amazon → altre categorie
   - Confidence = 3/3 = 100%

4. Quando confidence > 75%:
   - Genera FilterSuggestion
   - Mostra in "Suggerimenti IA"
   - Utente può accettare/ignorare

5. Se accettato:
   - Crea SmartFolder automatica
   - Applica filtro alle nuove email
   - Continua ad imparare
```

### Pattern Recognition

**Pattern Sender:**
```json
{
  "senderEmail": "noreply@amazon.it",
  "actions": [
    {"folder": "Shopping", "timestamp": 1234567890},
    {"folder": "Shopping", "timestamp": 1234567900},
    {"folder": "Shopping", "timestamp": 1234567910}
  ],
  "confidence": 1.0,
  "suggestion": "Crea filtro Amazon → Shopping"
}
```

**Pattern Domain:**
```json
{
  "domain": "company.com",
  "actions": 12,
  "mostCommonFolder": "Lavoro",
  "confidence": 0.83,
  "suggestion": "Filtro @company.com → Lavoro"
}
```


## 💡 Tips & Tricks

### Massimizza l'Efficienza

1. **Usa i suggerimenti IA**: Accettali per automatizzare
2. **Swipe rapido**: Più veloce dei menu
3. **Categorie custom**: Crea per i tuoi casi d'uso
4. **Dashboard**: Controlla statistiche settimanali
5. **VIP**: Identifica mittenti importanti
6. **Rumore**: Silenzia newsletter inutili

### Best Practices Filtri

**✅ Buoni Filtri:**
- Specifici: `@company.com` → Lavoro
- Ripetibili: Sempre stessa categoria
- Verificabili: Controlla match dopo creazione

**❌ Filtri da Evitare:**
- Troppo generici: `contains "email"` (troppo ampio)
- Conflittuali: Due filtri per stesso mittente
- Complessi: Troppe condizioni AND/OR/NOT
